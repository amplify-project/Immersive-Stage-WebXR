puente detenido

Crea la cámara virtual /dev/video10 (Insta360 Virtual) y la alimenta vía SDK. Tras inicializar, selecciónala arriba como fuente USB.

Si el stitching de la Insta360 retrasa el vídeo, el audio entra adelantado. Sube el delay (ms) hasta que casen; valor negativo adelanta el audio.

monitor parado

🎯 Medir sync (ffplay): abre una ventana fiel (<300 ms) en la máquina de producción con el delay actual aplicado — mira un transitorio (palmada/golpe), ajusta el delay y vuelve a medir. Requiere el server con DISPLAY (sesión gráfica). ▶ Vista navegador es solo aproximada (MSE añade latencia y sesga el vídeo). ⚠ usan el audio ALSA en exclusiva → párelos antes del directo. Equivale a ./monitor_sync.sh <ms>.

Check this only if the 4 capsules arrive raw (A-format). If the FOA is already converted to B-format upstream (plugin/DAW), leave it unchecked.
